# 💻 Code Analyzer Chatbot

A simple AI-powered code analysis chatbot built with **Streamlit, LangGraph, LangChain, and Groq LLM**.

## 🚀 Features

- Analyze pasted code snippets
- Identify syntax and logic issues
- Suggest improvements and optimizations
- Explain potential problems
- Maintain conversation history
- Uses Groq's Llama model for analysis

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- LangGraph
- Groq
- Llama 3.1
